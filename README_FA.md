# Punch Remote — اپ اندروید

کنترل بلوتوثی (BLE) دستگاه پانچ چرم. همه‌ی صفحه‌های نمایشگر دستگاه در اپ آینه می‌شن
و هر تغییر روی هر کدام (لمس دستگاه یا اپ) همان لحظه روی دیگری دیده می‌شه.

## ساخت APK با GitHub (بدون نصب هیچ چیز روی کامپیوتر)
1. در github.com یک مخزن (repository) جدید بساز (مثلاً `punch-remote`، Private هم باشه مشکلی نیست).
2. محتوای همین پوشه را **همان‌طور که هست** داخل مخزن آپلود کن
   (Add file → Upload files). مهم: پوشه‌ی مخفی `.github` هم باید آپلود بشه.
   اگر مرورگر پوشه‌ی مخفی را نشان نداد، از GitHub Desktop یا `git push` استفاده کن.
3. به تب **Actions** برو. workflow به اسم **Build APK** خودکار اجرا می‌شه
   (اگر نشد: Build APK → Run workflow).
4. بعد از ۴ تا ۷ دقیقه، روی اجرای سبز کلیک کن. پایین صفحه در بخش **Artifacts**
   فایل `LeatherPunchRemote-apk` را دانلود کن (zip است؛ داخلش `app-debug.apk`).
5. APK را روی گوشی بفرست و نصب کن (اجازه‌ی «نصب از منبع ناشناس» را بده).

اگر Build قرمز شد، متن خطا (از بخش Build debug APK) را برایم بفرست تا اصلاحش کنم.

## اولین اتصال
1. فریمور را روی ESP32 آپلود کن و دستگاه را روشن کن.
2. اپ را باز کن، PIN را وارد کن (پیش‌فرض `1234`، در `Config.h` فریمور قابل تغییر است)
   و Connect بزن. اجازه‌ی Bluetooth را بده.
3. بعد از چند ثانیه صفحه‌ی فعلی دستگاه در اپ ظاهر می‌شه.

## نکته‌ها
- دکمه‌ی **STOP** قرمز در همه‌ی صفحه‌ها هست و همیشه جلوتر از بقیه‌ی فرمان‌ها اجرا می‌شه.
- دکمه‌های `−/+` را نگه‌دار تا تکرار بشن.
- جوی‌استیک Manual: انگشت را نگه دار و بکش؛ رها کنی موتور می‌ایسته.
  اگر ارتباط قطع بشه، دستگاه خودش بعد از ۰٫۴ ثانیه جوی‌استیک را رها می‌کند.
- PIN فقط جلوی کنترل اتفاقی را می‌گیرد، رمزنگاری واقعی BLE نیست.

## تغییرات نسخه ۲ (هماهنگ با فریمور جدید)
- **صفحه‌ی Settings** مثل دستگاه شد:
  - ریزگام (Microstep) حالا با دکمه‌های `−` و `+` در لیست مجاز دستگاه (۱، ۲، ۴، ۵، ۸، ۱۰، ۱۶، ۲۰، ۲۵، ۳۲) جابه‌جا می‌شود
    (قبلاً ÷۲ و ×۲ بود). مقدار پیش‌فرض نمایش هم ۱/۱۰ شد.
  - زیر هر ردیف بازه‌ی مجاز نوشته شده (Ramp 2–25٪، Jog accel 1000–50000، Max speed 5–120، Course 10–50)
    و دکمه‌ی `−` یا `+` در حد مجاز غیرفعال می‌شود.
  - ردیف **Bluetooth** اضافه شد (فقط نمایشی: «CONNECTED»). روشن/خاموش کردنش فقط روی خود دستگاه ممکن است،
    چون خاموش کردنش اتصال اپ را قطع می‌کند.
  - بخش **Touch calibration**: راهنمای انجام کالیبراسیون روی دستگاه (از اپ قابل اجرا نیست).
  - بخش **About**: نام دستگاه، نسخه‌ی فریمور (از دستگاه خوانده می‌شود) و نسخه‌ی اپ.
  - مقدار «Driver pulses / motor rev» (مثلاً ۲۰۰۰ برای ریزگام ۱۰) به بخش Derived اضافه شد.
- **صفحه‌ی Done**: مثل دستگاه عنوان «<نام پروفایل> COMPLETE» و «FINAL POSITION ... MM» را نشان می‌دهد؛
  دکمه‌ها هم MENU و RESTART هستند.
- **صفحه‌ی Profile in progress** (پروفایل ناتمام): نام پروفایل ناتمام و توضیح دقیق دو گزینه
  (CONTINUE / CANCEL) مثل نمایشگر دستگاه نشان داده می‌شود.
- پروتکل BLE بدون تغییر است؛ فریمور را عوض نکن.
